MISIÓN 01 · BASE DE DATOS II · SEMANA 09

Configuración de red y conectividad remota

MÓDULO 01 · SQL SERVER

Prepara la instancia de Microsoft SQL Server para aceptar conexiones desde otros equipos de la red de forma controlada: identifica el servicio, habilita TCP/IP, fija el puerto 51433, permite conexiones remotas y abre el firewall.

🌐 RED Y PUERTOS 📡 TCP/IP 🛡️ FIREWALL
OBJETIVO DE LA MISIÓN // QUÉ DEBES LOGRAR

🎯 META

Dejar el motor de SQL Server escuchando en un puerto TCP estático conocido, con el protocolo de red habilitado, las conexiones remotas activadas y una regla de firewall que permita únicamente el tráfico necesario. Al terminar, la instancia debe estar lista para ser validada desde un equipo cliente.

ACTIVIDADES // CINCO PASOS PARA LA CONEXIÓN REMOTA
01

Identificar la instancia de SQL Server

Confirma qué instancia tienes instalada y que el servicio del motor esté en ejecución.

  • Presiona Windows + R, escribe services.msc y Enter.
  • Busca el servicio de SQL Server e identifica el nombre de la instancia.
  • Comprueba que el estado sea En ejecución.
✓

Resultado esperado: instancia identificada y motor activo.

02

Habilitar el protocolo TCP/IP

TCP/IP es el protocolo que usan las conexiones por red. Shared Memory solo sirve en el mismo equipo.

  • Ejecuta el Configuration Manager de tu versión: SQLServerManager15.msc (2019), SQLServerManager16.msc (2022) o SQLServerManager17.msc (2025).
  • Abre SQL Server Network Configuration → Protocols de tu instancia.
  • Haz clic derecho en TCP/IP → Enable.
✓

Resultado esperado: TCP/IP habilitado para recibir conexiones de red.

03

Configurar un puerto TCP estático — 51433

Con puertos dinámicos, SQL Server elige uno distinto en cada inicio. Un puerto fijo permite abrir una regla de firewall predecible.

  • En Configuration Manager → Protocols → doble clic en TCP/IP.
  • Pestaña IP Addresses → sección IPAll.
  • Deja TCP Dynamic Ports completamente vacío.
  • En TCP Port escribe 51433.
  • Acepta y reinicia el servicio SQL Server.
!

Importante: el reinicio es obligatorio para aplicar el cambio. Revisa que ninguna IP individual tenga valores que contradigan el puerto.

✓

Resultado esperado: SQL Server escucha en el puerto TCP 51433.

04

Habilitar las conexiones remotas desde SSMS

Esta opción controla si el servidor acepta conexiones desde otros equipos.

  • Abre SQL Server Management Studio y conéctate con autenticación de Windows.
  • Clic derecho sobre el servidor → Properties.
  • Entra en Connections.
  • Activa Allow remote connections to this server.
ℹ

Por sí sola no basta: también deben estar habilitados TCP/IP y la regla del firewall.

05

Configurar el Firewall de Windows

El firewall bloquea por defecto el tráfico entrante. Abre solo el puerto necesario.

  • Abre Firewall de Windows Defender con seguridad avanzada.
  • Reglas de entrada → Nueva regla → tipo Puerto.
  • Selecciona TCP y puertos locales específicos: 51433.
  • Acción: Permitir la conexión.
  • Aplica los perfiles que correspondan (Dominio / Privado / Público según tu red).
  • Opcional — Scope: restringe por direcciones IP remotas autorizadas.
!

Ojo: las IPs de ejemplo del material (192.168.1.100 / .101) no deben copiarse si no corresponden a tu red real.

✓

Resultado esperado: el firewall permite TCP 51433 (y, si se aplicó, solo desde IPs autorizadas).
